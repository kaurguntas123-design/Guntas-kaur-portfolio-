# Guntas Kaur Saini — Portfolio

## Run locally
Open `index.html` in a browser. For the best development experience, open this folder in VS Code and use the Live Server extension.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, `portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, `resume.pdf`, and this README.
3. Go to Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/ (root)`, then Save.

## Personalize before publishing
- Confirm the education dates and all contact details.
- Add your own portrait if desired; the current hero uses a designed monogram, not a stock photo.
- Add LinkedIn/GitHub profile URLs if you want them displayed.
- Review the résumé PDF included in this folder.
